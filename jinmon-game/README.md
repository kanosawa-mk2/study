# AI尋問ゲーム（プロトタイプ）

プレイヤーが容疑者へ自由に質問し、証拠を提示して自白を目指すコンソールゲームです。Javaがゲーム状態・証拠・ターン・勝敗を管理し、LLMは容疑者の台詞と感情だけを生成します。

## システム構成

`InterrogationGame`が進行の窓口となり、`GameState`が心拍数・緊張度・疑惑度・提示済み証拠・会話履歴・結果を保持します。`SuspectPromptBuilder`は容疑者設定や状態、直近の会話をプロンプトへまとめます。LLM接続は`LlmClient`インターフェースで抽象化し、OpenAI Responses API実装とAPIキー不要のデモ実装を切り替えられます。

プロバイダ接続を独立したアダプターにすることで、ゲームロジックを変更せず他社LLMやモックへ差し替えられます。履歴は直近20行に制限し、将来は要約器へ置き換え可能です。

## ディレクトリ構成

```text
src/main/java/dev/jinmon/
```

## 必要環境

- Java 21
- Maven 3.9以降

## APIキー設定と起動

キーをソースコードやREADMEに保存しないでください。環境変数から読み込みます。未設定の場合はデモモードで起動できます。

PowerShell:

```powershell
$env:OPENAI_API_KEY = "自分のAPIキー"
$env:OPENAI_MODEL = "gpt-5-mini" # 任意。省略時もこのモデル
mvn compile exec:java
```

APIキーなしで動作確認する場合:

```powershell
mvn compile exec:java
```

OpenAI接続は公式Responses APIの`/v1/responses`を使い、`text.format`のJSON Schemaで`dialogue`と`emotion`を受け取ります。APIキーを含みうるヘッダーやリクエスト本文はエラー表示に出しません。ネットワーク/APIの障害時はゲーム画面にエラーが表示されるため、APIキー設定や接続を確認してください。

## 遊び方

1. `1`で質問を入力します。
2. `2`で証拠を選んで提示します。
3. `3`で心拍数、緊張度、疑惑度、ターン数を確認します。
4. `4`で尋問を終了します。

緊張度35以上、疑惑度25以上、かつ証拠を1つ以上提示済みでクリアです。12ターンを超えると失敗します。証拠と追及に応じた加算値、終了判定はすべてJava側のルールです。

## LLMとJavaの責務

- **Java:** 会話履歴、提示証拠、ゲーム数値の更新、ターン制限、自白・失敗判定。
- **LLM:** 犯人を否認する佐藤として自然な返答と感情ラベルを生成。

LLMの出力からゲーム数値を読み取ったり、勝敗を決めたりしません。APIなしのテストでは`LlmClient`をラムダやモックに差し替えられます。

## テスト

```powershell
mvn test
```

ゲーム状態、証拠の重複防止、自白条件、ターン上限、履歴上限、プロンプト内容、モックLLMでの進行をテストします。
